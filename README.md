# ☕ cafe-landing

동네 카페 "모닝브루"를 소개하는 **간단한 카페 랜딩 페이지**입니다.
HTML과 CSS만으로 만들어져 있어 별도의 설치나 빌드 없이 바로 열어볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (헤더, 히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 디자인 스타일 (따뜻한 갈색 톤, 모바일 반응형) |

## 페이지 섹션

- **헤더**: 로고와 메뉴 이동 링크
- **히어로**: 메인 문구와 메뉴 보기 버튼
- **대표 메뉴**: 시그니처 라떼, 콜드브루, 크루아상 카드
- **우리 카페 이야기**: 카페 소개
- **오시는 길**: 주소, 영업시간, 문의 전화

## 사용 방법

1. 이 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/eric1147/cafe-landing.git
   ```

2. `index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 수정 안내

카페 이름, 주소, 전화번호, 메뉴 가격은 모두 **예시 내용**입니다.
`index.html`에서 실제 정보로 바꿔서 사용하세요.
